# 食刻/咔嚓算卡 项目长期备忘

## 产品与账号
- 代码项目名：食刻(shike)；对外小程序名：「咔嚓算卡」(AI拍照算热量+重油校准+对赌挑战+晒餐海报)
- 公众号：「何以解馋的小记」(作者小何，上海)
- README里"食刻"含5人对赌功能，公众号推文主推AI算热量，对赌功能已上线但历史推文未推(2026-08起作为新方向)

## 运营现状(2026-08-12)
- 冷启动期：公众号粉丝几十到几百级(<1万)，头条阅读1-16(仅1次100爆款)，打开率约4%
- 小程序用户：几十到几百(亲友+小范围测试)
- 外部渠道：只做了小红书(在发配图)，无短视频/无私域社群
- 小程序→公众号导流：未接(最大漏点)

## 核心认知(最重要)
- 涨粉瓶颈是"流量入口"不是"内容"。公众号是封闭池+低权重，微信不推非粉丝，内容再好只在基本盘转=空房间演讲。
- 用户科普/争议/攻略各种内容都发过阅读都低→证实非内容类型问题。
- 公众号应定位为"承接外部流量、沉淀粉丝"，而非指望站内自然破圈。
