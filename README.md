# 食刻 (ShiKe) — 基于 AI 视觉的极简热量管理与私密对赌小程序

---

## 🌟 项目简介 (One-Sentence Pitch)
**食刻 (ShiKe)** 是一款结合了 **“AI 拍照识别”** 的极简热量追踪工具与 **“熟人私密对赌”** 社交机制的健康生活小程序。我们旨在通过 AI 技术降维打击传统卡路里工具的极高录入摩擦，用趣味对赌契约消灭伪自律，帮用户快乐、轻松地达成减脂与健康管理目标。

项目核心特色是：**记录零摩擦、视觉极致美感、对赌真实刺激、烹饪油水可校准**。

---

## 🔥 核心特色与解决痛点

### 1. 拍照即出结果 — 告别“做数学题式”的手动记录 📸
*   **痛点**：传统软件录入繁琐，吃顿饭需要搜克数、拿秤称重，次周留存率极低。
*   **食刻破局**：全面拥抱多模态大语言模型，用户饭前随手一拍，秒级识别盘中菜品，估算克数并自动累加碳水、蛋白质、脂肪和总热量。

### 2. 首创“中餐油脂修正算法” — 解决 AI 在重油烹饪上的盲区 🧪
*   **痛点**：中餐烹饪极其复杂，外卖、食堂和水煮菜的油量相差巨大，大模型视觉很难一眼识别隐形油水，导致估算偏差高达 25%。
*   **食刻破局**：在 AI 识别结果下提供**“油脂滑块（清淡/适中/重油）”**。选择“清淡”热量自动下浮 10%，“重油”上浮 15%，用简单的手势微调，抓死这 25% 的隐形热量差距。

### 3. 5 人私密对赌小队 — 拒绝“塑料友情式减脂” 🤝
*   **痛点**：大厅发帖没人看，微信群监督没有约束力，立 Flag 容易，默契断更更容易。
*   **食刻破局**：采用私密邀请码机制（如 `A8X2B`）组建 2-5 人闺蜜/好友挑战赛。每人扣除 150 契约分。7 天挑战期内，**任何偷吃超标或漏记打卡的人，本金直接被没收并由小队全勤的小伙伴“均分”！** 赢家不仅自律，还能分得奖金！

### 4. 高清磨砂玻璃拟态海报 — 满足“自律打卡成就感” 🎨
*   **痛点**：保存的海报字迹模糊、像素低，或者不小心误拒相册权限后功能死锁。
*   **食刻破局**：基于 Canvas 2D 的 2 倍物理分辨率高清制图，生成质感拉满的渐变背景与磨砂玻璃打卡图。配备“防翻车”权限引导，误拒相册后可一键跳转重新授权，绝不死锁。

### 5. 静默降级守护 — 即使断网也永不闪退 🛡️
*   **痛点**：网络信号差、API 超时或格式错乱时，传统 AI 工具直接弹红字报错甚至崩溃闪退，极其挫伤记录热情。
*   **食刻破局**：后台编写了“静默守护降级机制”。在网络断开或 AI 故障时，系统会自动静默加载“经典低卡备用餐”并存入数据库，确保用户记录绝对不被中断。

## 🛠️ 全栈技术选型

项目本着 **“Java 筑基稳定性，AI 冲锋生产力”** 的敏捷开发策略构建：

*   **前端**：微信原生小程序 (磨砂玻璃 CSS 拟态滤镜、Canvas 2D 绘图接口、无感微信登录集成)
*   **后端**：Java 17 + Spring Boot 3 + JPA / Hibernate 6 (企业级三层架构、多渠道多模态 AI 视觉适配器)
*   **数据库与缓存**：MySQL 8.0 (JSON列直接绑定Java类特性) + Redis (看板高速缓存、对赌深夜清盘结算分布式锁)
*   **AI 视觉支持**：集成 OpenAI 兼容多模态接口（适配 GPT-4o-mini、通义千问 Qwen-VL、智谱 GLM-4V、Gemini Vision 等）

## 📈 变现路径与商业蓝图 (Monetization)
1.  **用户规模 < 5000 (冷启动期)**：全功能免费，收集数据持续优化提示词精度。
2.  **用户规模 5000 - 5万 (成长期)**：上线“食刻集市”（达人减脂餐付费计划，平台抽佣 20%）；官方押金挑战赛（契约抽水 10%）。
3.  **用户规模 5万+ (成熟期)**：推出食刻 Pro 会员（AI周度营养报告、AI定制食谱）；原生健康品牌（如轻食沙拉、全麦面包）在结果分析页的软性智能匹配推荐。
