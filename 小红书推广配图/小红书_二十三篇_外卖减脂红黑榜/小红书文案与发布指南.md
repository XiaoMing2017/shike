💣 避雷！外卖 4 大隐形“吸油黑榜”：

1️⃣ 炒茄子 / 地三鲜 / 干锅花菜：
多孔海绵结构，炒菜时疯狂吸油！一盘看似清爽的炒茄子能吸附 35g 烹饪油（300+ kcal 隐形纯油），热量直接反超大碗麻辣烫！

2️⃣ 骨汤麻辣烫 / 浓汤米线：

3️⃣ 蔬菜沙拉（淋香焙芝麻酱）：
一小包丘比香焙芝麻酱（约 30g）= 200 大卡纯脂肪，相当于你白白多吃了大半碗米饭！

4️⃣ 炒河粉 / 炒米粉 / 凉皮：
纯精制碳水 + 大油猛火翻炒，热量比同等分量的蒸米饭高出 2.5 倍！

🍲 2. 麻辣烫清汤公式 (~400 kcal)
👉 点法：清汤/番茄汤底 + 魔芋丝 + 巴沙鱼/鸡胸肉 + 豆腐 + 海量绿叶蔬菜，调料选蒜泥香菜加少许生抽，避开浓稠麻酱！

🍱 3. 中餐炒菜刷油公式 (~500 kcal)
👉 点法：米饭只吃小半碗（慢碳水） + 白灼虾/卤牛肉/清蒸鱼（优质蛋白） + 随餐备一碗温水将炒青菜涮一涮！
