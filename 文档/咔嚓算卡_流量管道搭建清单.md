# 咔嚓算卡 · 流量管道搭建清单

> 诊断结论：你阅读低不是内容问题，是流量入口没接通。
> - 小程序：几十到几百用户，但 → 公众号导流**没接**（最大漏点）
> - 小红书：在发配图，但 → 公众号/小程序导流**没做**（最大浪费的公域口）
> - 公众号是封闭池，<1万粉+低权重，微信不推非粉丝 → 内容再好也只在基本盘转

# 破局：从"换内容"转向"接管道"

## 管道 1：小程序 → 公众号（今天就能做，0成本，最快落地）

小程序那几十到几百用户是最精准的，转成公众号粉丝是白捡的增量。

**动作：**
1. 小程序首页加 banner：「关注公众号，免费领《外食热量红黑榜》」
2. 打卡完成页加引导：「关注公众号领每周定制食谱」
3. 晒餐海报底部加公众号二维码 + 一句引导
4. 诱饵选《外食热量红黑榜 PDF》或「Pro 周卡」

**预期：** 几十到几百用户 × 20% 转化 = 几十高粘性粉丝（比公众号内容涨粉快 10 倍）

## 管道 2：小红书 → 公众号/小程序（最大公域流量口，长期破圈主力）

小红书是公域，有自然推荐流量，是冷启动期唯一能"免费破圈"的渠道。你在发但没导流 = 把流量倒进了下水道。

**动作：**
1. 小红书主页简介加：「减脂干货在公众号：何以解馋的小记 ｜ 算热量小程序：咔嚓算卡」
2. 每篇笔记结尾引导句：「完整热量表公众号回复【热量】领」
3. 爆款笔记评论区置顶：「拍照算热量用小程序咔嚓算卡，免费」
4. 私信暗号：用户私信「食谱」→ 回复引导关注公众号

**注意：** 小红书不能直接放公众号链接，用「简介 + 私信 + 暗号」组合，别硬刚平台规则。

## 管道 3：私域冷启动（最直接的人脉流量）

**动作：**
1. 每篇公众号文章，发动 5-10 个朋友转发朋友圈（朋友的朋友 = 二度人脉，冷启动期最直接的新流量）
2. 建减脂打卡群：小程序用户 + 朋友拉入，群内发文章 + 打卡
3. 朋友圈固定栏目：每周一发「上周减脂战报」
