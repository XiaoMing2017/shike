## 14 维文风 DNA

### 1. 语气基调
- 第二人称"你"对话体，亲切紧迫，不爹味不说教
- 关键句用命令式关怀："快停下！""快停下自责！""根本不是你的错"
- 像一个懂行的闺蜜在急切拉你一把，先共情后反转

### 2. 叙事节奏
- 短句为主，3-4 行一段，移动端留白充足
- 大量"——"破折号制造停顿与悬念
- 讲机制时用箭头"➔"串联因果，长逻辑不拆段

### 3. 句式与句长
- 情绪句极短（"陷入崩溃。""快停下！"）
- 机制句偏长但用符号切分（"热量赤字过大 + 高强度有氧 ➔ 身体以为你面临生命威胁 ➔ 刺激 HPA 轴暴发皮质醇 ➔ 强行潴留水分"）
- 善用"明明……却……""白天……可一到晚上……"对比句式

### 4. 用词偏好
- **科学术语高频**：揭秘、真相、机制、内分泌、神经、激素、皮质醇、瘦素、多巴胺、血清素、色氨酸、HPA轴、VTA、暴发、骤降
- **程度副词夸张**：彻底、极度、疯狂、死死、狠狠、神级、硬核、黄金
- **数字密集**：50%、300mg、110-120、7-10天、1.5倍、38元/月
- 中英混排：术语后括号注英文（Cortisol、Leptin、NPY、Tryptophan）

### 5. 情绪曲线
焦虑共鸣开头（😭自责/崩溃）→ 反转安慰（"不是你的错"）→ 科学揭秘（权威感）→ 实操方法（掌控感）→ 产品方案（解法）→ 免费强调（零门槛）→ 行动号召

### 6. 开头公式（3 篇一致）
**场景化痛点开头 + 😭emoji + "明明……却……"对比句**
- 样本A："明明顿顿吃减脂餐、甚至每天都在坚持跑步——可坚持了整整一周，踩上体重秤，数字居然纹丝不动！😭"
- 样本B："白天吃得清清淡淡，意志力爆棚——可一到晚上加班或者躺在床上，大脑就疯狂发出吃甜食……😭"
- 样本C：换成平铺疑问句，**没有emoji、没有对比冲突** → 这是它阅读最低的结构原因之一

### 7. 结尾公式
"🚀 立即 + 行动号召"收尾 + 前置"🎁 最重要的一点：100% 完全免费！" + 对比"市面上 38 元/月"

### 9. 标点与符号习惯
- 破折号"——"：高频，制造转折/悬念
- 感叹号"！"：高频，情绪驱动
- 箭头"➔"：串联因果链
- 方括号【】：标注功能名（【AI 专家级营养健康诊断】）
- emoji 当章节前缀：🔬💡🛠️🎁🚀❌✅🤔

### 10. 标题公式
**爆款公式（A/B 两篇）**：`[情绪钩]！揭秘[痛点]的[科学X]真相/机制 + [数字][方法]，完全免费！`
- 必含四钩：情绪（别再瞎虐/别再怪罪）+ 权威（揭秘+神经/内分泌）+ 方法（7天/3招）+ 零门槛（完全免费）
- 样本C 疑问句式、无四钩 → 扑街，**反证公式有效**

### 11. 产品植入方式
- 固定独立板块"🛠️ 怎么用「咔嚓算卡」……？"
- 4 个功能点 emoji 罗列，强调"全新【XX】"
- 必跟"🎁 100% 完全免费" + 对比市面 38 元/月
- 软性逻辑：先科普痛点 → 再给方法 → 最后"不知道怎么把控？用咔嚓算卡"
- 产品名一律用「咔嚓算卡」（书名号包裹）

### 12. 权威构建手法
- 密集科学术语 + 英文学名 + 生理机制链
- 营造"不是玄学是科学"的可信感
- 数据支撑（百分比、mg、心率区间）

### 13. 互动设计
- 样本C 有"💬 互动话题：你现在减脂遇到的最大困难？"
- 样本 A/B **无互动钩子** → 这是爆款也 0 评论的原因
- **缺口**：缺转发诱因、缺评论区预埋、缺涨粉钩子

### 14. 视觉排版规范
- emoji 作结构化分隔符（章节标）
- 配图指南编号（"配图指南 05"）
- 莫兰迪色系晒餐海报
- 段间空行，移动端友好
