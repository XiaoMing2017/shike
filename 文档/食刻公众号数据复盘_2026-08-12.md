## 二、爆款拆解：100 阅那篇为什么能爆

```
别再瞎虐自己！  →  情绪钩（自嘲/共鸣："你说的就是我"）
```

**爆款公式**：**情绪钩 + 权威钩 + 方法钩 + 零门槛钩**，标题字数 80+，信息密度极高。

## 三、扑街共性：6 篇为什么死（4 个元凶）

1. **标题"信息密度低"**：失败标题普遍 < 30 字，钩子不超过 2 个。
2. **缺乏"零门槛"承诺**：减脂号用户最怕"又要运动/又要忌口"，标题里没有"免费/不饿/不运动"这类减压承诺。
3. **发布时间不是核心变量**：17:00-17:30 同时间，星期一 1 阅 vs 星期五 100 阅——时间从来不是核心，**标题决定下限，内容决定上限**。
4. **互动为 0 = 没有传播**：除了"市面 AI"那篇有 1 条评论，其余全部 0 互动——冷启动期没有"评论钩子"和"转发诱因"，单篇就成了孤岛。

## 四、标题工程 SOP（立即执行）

每篇标题必须自检 4 个钩子（最少命中 3 个）：

| 钩子 | 关键词库 | 作用 |
|------|---------|------|
| 情绪钩 | 别再 / 学不会 / 我也 / 闺蜜 / 自嘲 | 制造"我也是"共鸣 |
| 权威钩 | 揭秘 / 真相 / 医生不会告诉你 / 神经机制 | 召唤好奇心 |
| 方法钩 | 7 天 / 3 招 / 5 个 / 公式 / 清单 | 承诺具体可执行 |
| 零门槛钩 | 免费 / 不饿 / 不运动 / 不忌口 / 拍照 | 消除最后一公里 |

**爆款公式（直接套）**：
> `[情绪钩]！+ [权威钩"]+ [数字] + [方法钩]，[零门槛]！`

食刻专属模板示例：
- 《别再饿肚子！神经科医生揭秘"越饿越胖"真相 + 7 天吃饱冲刺法，完全免费！》
- 《闺蜜靠一招暴瘦 8 斤！揭秘"对赌式减脂"机制 + 3 招拿走，不忌口不运动！》

## 五、微信"贴图"功能（被严重低估的涨粉开关）

后台那条蓝色提示——**"把文章也发表为贴图，让更多人发现好内容"**——是微信给公众号增加的一个冷启动流量口：

- **机制**：把文章同步发布为"公众号贴图"形态，出现在订阅号信息流的"图文"卡片里，用户无需点开就能看到封面+标题+摘要。
- **优势**：相比普通图文，贴图打开率平均高 30%-50%（微信官方资源倾斜）。
- **建议**：每篇必开"贴图"开关——这是 0 成本白拿的曝光。
