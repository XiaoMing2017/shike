# 萌宠 2D 动画系统 V1.0
## 程序实现规格书

**版本：V1.0**  
**平台：微信小程序**  
**技术方向：Canvas 2D + 分层 PNG + 自研轻量动画系统**  
**目标：实现具有“生命感”的 2D 萌宠**

---

# 1. V1.0 开发目标

V1.0 不做完整宠物 AI，而是先建立一个可扩展的：

> **2D 分层宠物动画引擎**

系统必须支持：

```text
PNG 分层素材
    ↓
独立身体部件
    ↓
锚点 / Pivot
    ↓
动画时间轴
    ↓
状态机
    ↓
随机行为
    ↓
微动作
    ↓
Canvas 渲染
```

最终实现：

- 宠物待机
- 呼吸
- 眨眼
- 尾巴摆动
- 耳朵运动
- 眼睛看向不同方向
- 四肢独立运动
- 行走
- 停止
- 坐下
- 趴下
- 起身
- 跳跃
- 伸懒腰
- 睡觉
- 自主随机行为
- 动作自然过渡

# 5. RenderNode

每个身体部件都是一个 RenderNode。

例如：

```text
Pet
│
├── shadow
├── backLegL
├── backLegR
├── body
├── tail
├── frontLegL
├── frontLegR
├── head
├── earL
├── earR
├── eyeL
└── eyeR
```

RenderNode 数据结构：

```ts
interface RenderNode {
  id: string;

  image: CanvasImageSource;

  x: number;
  y: number;

  scaleX: number;
  scaleY: number;

  rotation: number;

  pivotX: number;
  pivotY: number;

  opacity: number;

  visible: boolean;

  zIndex: number;
}
```

```ts
interface Transform {
  x: number;

  scaleY: number;

  rotation: number;

  opacity: number;

```

默认值：

```ts
{
  x: 0,
  y: 0,
  scaleX: 1,
  scaleY: 1,
  rotation: 0,
  opacity: 1
}
```

# 7. Pivot 锚点系统

这是 V1.0 最重要的基础功能之一。

例如腿：

```text
       肩膀
        ● ← Pivot
        │
        │
        │
        ●
```

旋转必须围绕：

```text
pivotX
pivotY
```

而不是图片中心。

Canvas 绘制：

```ts
ctx.translate(node.x, node.y);
ctx.rotate(node.rotation);
ctx.scale(node.scaleX, node.scaleY);

ctx.drawImage(
  node.image,
  -node.pivotX,
  -node.pivotY
);
```

# 14. 动画插值

动画不能直接跳值。

必须：

```text
Start
 ↓
Interpolation
 ↓
End
```

基本公式：

```ts
value =
start +
(end - start) * progress;
```

其中：

```ts
progress = elapsed / duration
```

# 16. 基础生命层

基础生命层永远运行。

```text

```

架构：

```text

      │
      ├── Breathing
```

```text

```

# 41. MicroBehavior

MicroBehavior 不改变主状态。

例如：

```text
Idle
```

同时可以：

```text
Blink
EarMove
TailMove
Look
HeadTilt
```

所以：

```text
主状态 = WALK

微动作：
Blink
```

也是允许的。

---

# 42. MicroBehavior 优先级

```text
Blink      低
EarMove    低
TailMove   低
Look       中
HeadTurn   中
```

```text

```

```text

```

避免动画冲突。

# 47. Delta Time

不能假设：

```text
每帧 = 16.67ms
```

必须：

```ts
deltaTime =
currentTime -
lastTime;
```

然后：

```ts
animator.update(deltaTime);
```

这样不同设备帧率下动画速度一致。

# 50. RenderNode 绘制

伪代码：

```ts
drawNode(node) {

  if (!node.visible) return;

  ctx.save();

  ctx.globalAlpha = node.opacity;

  ctx.translate(
    node.x,
    node.y
  );

  ctx.rotate(
    node.rotation
  );

  ctx.scale(
    node.scaleX,
    node.scaleY
  );

  ctx.drawImage(
    node.image,
    -node.pivotX,
    -node.pivotY
  );

  ctx.restore();
}
```

# 81. 给 AI 编程助手的开发要求

开发时必须遵守以下原则：

```text
1. 不要把动画逻辑全部写死在页面代码里。

2. 不要把宠物做成一张完整图片。

3. 不要使用 GIF 作为主要动画方案。

4. 不要让 Walk、Jump 等动画直接修改世界坐标。

6. 身体动画由 Local Transform 控制。

7. 所有身体部件必须支持独立 Transform。

8. 所有旋转必须基于 Pivot。

9. 动画必须使用 DeltaTime。

10. 动画配置尽量 JSON 化。

11. 行为必须通过 StateMachine 管理。

12. 随机行为必须带权重和 Cooldown。

13. 微动作必须能够与主行为同时存在。

14. 图片必须预加载并缓存。

15. 必须提供 Debug 模式。

16. V1.0 不引入不必要的第三方动画引擎。

17. 代码必须模块化，后续可以增加狗、兔子、狐狸等不同宠物。

18. 不允许为了实现第一只猫而把架构写成“猫专用代码”。
```

# 83. 最终架构原则

整个 V1.0 最重要的不是代码量。

而是必须坚持：

```text
               世界
                │
                ↓
             PetRoot
                │
          世界位置/方向
                │
                ↓
            PetLocal
                │
        ┌───────┼───────┐
        ↓       ↓       ↓
       Body    Head    Tail
        │       │       │
       Legs    Eyes    ...
        │
        ↓
     Animation
        │
        ↓
      State
        │
        ↓
     Behavior
        │
        ↓
      Random
```

**一句话总结：**

> **PetRoot 决定“宠物在哪里”，StateMachine 决定“宠物要做什么”，Animator 决定“宠物怎么做”，RenderNode 决定“宠物身体怎么动”，BehaviorManager 决定“下一步做什么”，MicroBehavior 决定“它为什么看起来像活的”。**

这就是 V1.0 的核心架构。
