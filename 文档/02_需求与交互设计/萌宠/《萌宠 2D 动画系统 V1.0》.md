# 一、你的角色

你现在是一名：

> **资深微信小程序工程师 + 2D 动画引擎工程师 + 游戏客户端架构师**

你需要在当前微信小程序项目中，实现：

> **萌宠 2D Animation Engine V1.0**

目标不是制作一个 GIF 播放器，而是建立一个：

> **“分层 2D 宠物身体部件 + 独立 Transform + Pivot + Keyframe Animation + Animation Layer + State Machine + Random Behavior + Micro Behavior”**

组成的轻量级 2D 宠物动画系统。

# 七十、最重要的验收标准

不要只判断：

> “代码能运行。”

必须判断：

> **“看起来是不是一只活着的小动物。”**

重点观察：

### 1. 呼吸

不能像：

```text
放大
缩小
放大
缩小
```

而应该：

> 非常轻微。

### 2. 眨眼

不能：

> 固定频率。

而应该：

> 偶尔发生。

### 3. 走路

不能：

> 四条腿机械摆动。

而应该：

> 身体、腿、头、尾巴有轻微协同。

### 4. 跳跃

不能：

> 整体上下移动。

而应该：

> 蓄力 → 起跳 → 空中 → 落地 → 缓冲。

### 5. Idle

不能：

> 完全不动。

而应该：

> 呼吸 + 偶尔眨眼 + 尾巴 + 耳朵 + 眼神。

# 最终原则

整个开发过程中始终记住：

> **PetRoot 决定宠物在哪里。**

> **StateMachine 决定宠物做什么。**

> **BehaviorManager 决定宠物下一步做什么。**

> **Animator 决定动作怎么发生。**

> **RenderNode 决定身体哪个部位怎么动。**

> **MicroBehavior 决定它为什么看起来像活的。**

> **Canvas 负责最终显示。**

不要破坏这个职责边界。
